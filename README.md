## 上传到 GitHub Pages
1. GitHub → New repository → 名字随意（例如 costie）→ Public → Create
2. Add file → Upload files → 把这个文件夹里的全部东西（包括 icons 文件夹）拖进去 → Commit
3. Settings → Pages → Source: Deploy from a branch → main / (root) → Save
4. 等 1–2 分钟，网址是 https://你的用户名.github.io/仓库名/

## Firebase
- Authentication → 登录方法 → Google → 启用
- Authentication → 设置 → 已获授权的网域 → 添加 你的用户名.github.io
